## Повторение

```sh
npm run build:vocabulary
npm test
python3 -m http.server 8000
```

На **отдельном тестовом адресе** откройте `/tests/browser-runner.html` и нажмите Run regression suite. Набор заменяет localStorage тестовыми данными на своём origin. Вручную осмотреть размеры можно через `/tests/preview.html`.

CLI-вариант: установите Playwright и запустите `npm run test:browser`; системный Chromium задаётся через `CHROMIUM_PATH`. В этой среде отдельный запуск Chromium из shell был запрещён; тот же набор успешно выполнен через поддерживаемый браузерный preview. CLI-обёртка сама по себе в этой среде не прошла запуск, поэтому её результат не заявляется как PASS.
