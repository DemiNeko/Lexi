# lexi. — Academic English

Независимый тренажёр слов из **Units 1–3 Cambridge Academic English Intermediate (B1+)**.
181 слово и выражение: Unit 1 — 60, Unit 2 — 55, Unit 3 — 66.

## Запуск без установки

Открой `index.html` в современном браузере. Папка `assets` должна оставаться рядом.
Сборка, npm install, API-ключи, сервер и база данных не нужны.

Отдельный файл `Lexi.html`, выданный вместе с архивом, — автономная копия приложения
с включёнными стилями, кодом и словарём. Он не нужен для публикации репозитория.
Если браузер запрещает localStorage для локальных файлов, тренажёр предупредит об этом;
прогресс можно экспортировать. Для стабильного постоянного адреса используй GitHub Pages.

## Что внутри

- **Карточки:** вспомни перевод, переверни, отметь «Помню» / «Ещё повторить».
- **Тест:** четыре варианта перевода и разбор после ответа.
- **Написание:** ввод перевода без вариантов, EN → RU / RU → EN / вперемешку.
- **Словарь:** поиск на двух языках, примеры, заметки, печатные страницы, сохранённые слова.
- **Повторение:** сложное слово возвращается через три других задания, если они остались;
  не больше двух дополнительных повторов одного слова в сессии.
- **Прогресс:** дневная цель, серия дней, статистика, восстановление незаконченной сессии.
- **Дизайн:** светлая и тёмная темы, мобильная навигация, клавиатура, reduced motion.
- **Данные:** экспорт/импорт JSON. Нет регистрации, аналитики или облачной синхронизации.

Первое правильное воспоминание назначает повтор через 1 день, следующие — через 3, 7,
14 и 30 дней. Ошибка сбрасывает серию слова и назначает повтор через 10 минут.
После трёх правильных ответов подряд слово получает пометку «Уверенно».
Это простой учебный алгоритм, не проверка преподавателя и не гарантия запоминания.
Результаты карточек основаны на самооценке.

### Ограничения проверки и звука

Написание проверяется по переводу/синонимам из карточки, без ИИ. Не учитываются регистр,
лишние пробелы, различие е/ё и некоторые знаки препинания. Указанные британские/
американские варианты принимаются. Произвольный верный синоним, которого нет в карточке,
может быть не принят — для него нужно дополнить словарь. Достаточно одного русского
значения. Слова и фразы проверяются в начальной форме, не во всех грамматических формах.

Озвучивание использует `speechSynthesis`. Нужен английский голос устройства/браузера;
он может загружаться не сразу и может требовать интернет. Тренажёр не отправляет
прогресс или словарь своему серверу. Озвучивание на реальном устройстве нужно проверить отдельно.

## Публикация в GitHub Pages: Windows

**Сам архив ещё не является опубликованным сайтом.** Скрипт выполняет публикацию
в аккаунте, в который ты войдёшь через GitHub CLI.

1. Полностью распакуй архив в отдельную папку.
2. Установи Git и GitHub CLI, если их ещё нет:

```powershell
winget install --id Git.Git --exact
winget install --id GitHub.cli --exact
```

3. После установки закрой и заново открой терминал. Дважды нажми **`publish.cmd`**.
   Он запустит `publish.ps1` с разрешением исполнения только для этого процесса PowerShell.
   Общесистемная политика исполнения не изменяется. Перед запуском скрипт можно прочитать.
4. При необходимости откроется авторизация GitHub в браузере. Пароли/токены в чат не нужны.
   Проверь показанный аккаунт и подтверди публикацию буквой **Y**.

Скрипт создаст **публичный** репозиторий `lexi-academic`, отправит файлы, включит Pages
из `main` → `/ (root)` и попробует дождаться успешной сборки и HTTP-проверки сайта.
Неопубликованный или ещё собирающийся сайт не будет объявлен проверенным.
PDF учебника, браузерный прогресс и локальные секреты не публикуются.
Скрипт добавляет только явно перечисленные файлы и отказывается публиковать чужой origin.

Другое имя репозитория:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\publish.ps1 -RepoName lexi-units-1-3
```

При повторном запуске из той же папки скрипт обновляет тот же репозиторий без force push.
Если имя занято, но папка с ним не связана через origin, он остановится: выбери другое имя.

Коды завершения: `0` — публикация и HTTP-проверка успешны (или отмена пользователем);
`1` — ошибка; `2` — файлы отправлены, но завершение публикации ещё не подтверждено.

### Ручная публикация через сайт GitHub

Создай пустой публичный репозиторий и загрузи `index.html`, `assets` и `.nojekyll`.
Затем **Settings → Pages → Deploy from a branch → main → / (root) → Save**.
Ссылка появится в Settings → Pages; ход публикации — во вкладке Actions.
Не добавляй в репозиторий PDF учебника или JSON с твоим личным прогрессом.

## Структура

```text
index.html             разметка приложения
assets/style.css       дизайн и адаптивность
assets/app.js          интерфейс, тренировки, хранение прогресса
assets/words.js        словарь, который загружает браузер
assets/icon.svg        иконка сайта
vocabulary.json        тот же словарь в обычном JSON
publish.ps1            создание репозитория и настройка Pages
publish.cmd            запуск скрипта в Windows
.nojekyll              публикация как статических файлов
SOURCES.md             источник и границы подборки
TESTING.md             выполненные проверки и ограничения
package.json           только удобная команда npm test, без зависимостей
tests/check.mjs       проверка целостности словаря
```

Для изменения слова редактируй `vocabulary.json` и синхронно `assets/words.js`.
Идентификатор `id` существующего слова лучше не менять: по нему хранится прогресс.
Новые слова можно добавлять в таком же формате, но тест количества нужно обновить.

## Проверка

При установленном Node.js:

```sh
npm test
```

Команда проверяет синтаксис JavaScript, количество/уникальность слов, номера страниц,
переводы и совпадение JSON с JS. Установка npm-пакетов не требуется.
