# Lexi — vocabulary from Units 3–5

Статический тренажёр по текстам Cambridge Academic English, Intermediate. Русский и казахский языки; светлая и тёмная темы с основным цветом `#4E6851`. Карточки, тест, написание, закладки, интервальное повторение и локальный прогресс.

## Текущая подборка

353 уникальные карточки из 19 связных текстов, включая статьи, образцы эссе, диалог и учебные абзацы с пропусками. Это учебный отбор содержательной лексики, а не перечень каждого слова книги.

| Unit | Тема | Карточек | Текстов |
|---|---|---:|---:|
| 3 | Indications and trends | 98 | 6 |
| 4 | The information age | 147 | 6 |
| 5 | On budget | 124 | 7 |

15 карточек относятся к нескольким юнитам, поэтому сумма по юнитам больше общего количества. Фильтр «Текст из книги» работает в словаре и во всех режимах практики. Под каждой карточкой показаны источники и печатные страницы **текста целиком**.

## Запуск

Откройте `index.html` или раздавайте папку статическим сервером, например `python3 -m http.server 8000`. Для GitHub Pages достаточно файлов в корне и `assets/`; сборка приложения не требуется. Учебные данные встроены в `assets/words.js`, внешних API и шрифтов нет.

## Совместимость

- Все 181 исходных ID и их словарные поля сохранены. Сохранены также все 759 ID из предыдущего патча Units 1–4.
- Всего в базе 903 карточки: 353 в текущем курсе, 550 в доступном через словарь архиве. Архивные карточки можно искать, сохранять и тренировать отдельно.
- Ключи `lexi-progress-v1`, `lexi-session-v1`, формат экспорта `version: 1`, история ответов, сроки повторения и закладки сохранены. Старые направления `en-ru` / `ru-en` преобразуются в языконезависимые.
- Старый выбор Unit 1/2 заменяется на «Все юниты», но данные этих карточек остаются. Незавершённая старая сессия может содержать архивные слова и продолжает работать.
- При смене хоста/браузера нужно перенести JSON через экспорт/импорт: localStorage привязан к адресу сайта.

## Данные и проверки

`npm run build:vocabulary` воспроизводимо собирает `vocabulary.json` и `assets/words.js` из исходных данных. Новые постоянные ID закреплены в `data/reading-identities.json`; не перенумеровывайте их. Принадлежность текущему курсу хранится отдельно в `readings` / `readingUnits`, историческая — в `unit` / `units`.

`npm test` — проверка данных, исходных записей, покрытия источников и воспроизводимости. Браузерный набор можно запустить на отдельном тестовом адресе через `tests/browser-runner.html` или `npm run test:browser` с установленным Playwright. Набор использует тестовые данные localStorage: не запускайте его на адресе со своим учебным прогрессом. См. `TESTING.md`.

Состав источников — `SOURCES.md`, визуальная система — `DESIGN.md`.
